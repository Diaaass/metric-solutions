# Metric Solution - Сайт компании по геометаллургии

Корпоративный сайт для компании Metric Solution, специализирующейся на геометаллургии и обогащении полезных ископаемых.

## 🚀 Технологический стек

- **Next.js 14** (App Router)
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (иконки)

## 📁 Структура проекта

```
metric-solution/
├── src/
│   ├── app/                    # Страницы (Next.js App Router)
│   │   ├── about/             # О компании
│   │   ├── services/          # Услуги
│   │   ├── projects/          # Проекты
│   │   ├── team/              # Команда
│   │   ├── blog/              # Блог
│   │   └── contacts/          # Контакты
│   ├── components/            # React компоненты
│   │   ├── layout/           # Header, Footer
│   │   ├── ui/               # UI компоненты
│   │   ├── forms/            # Формы
│   │   └── sections/         # Секции страниц
│   ├── types/                # TypeScript типы
│   └── data/                 # Моковые данные
└── public/                   # Статические файлы
```

## 🛠 Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Сайт откроется по адресу [http://localhost:3000](http://localhost:3000)

### 3. Сборка для продакшена

```bash
npm run build
```

### 4. Запуск продакшен версии

```bash
npm start
```

## 📄 Страницы сайта

1. **Главная** (`/`) - Hero, услуги, статистика, форма консультации
2. **О компании** (`/about`) - Информация о компании, миссия, ценности
3. **Услуги** (`/services`) - Список всех услуг
   - Геометаллургия (`/services/geometallurgy`)
   - Баланс металлов (`/services/metal-balance`)
   - Исследование руды (`/services/ore-research`)
4. **Проекты** (`/projects`) - Кейсы и реализованные проекты
5. **Команда** (`/team`) - Информация о специалистах
6. **Блог** (`/blog`) - Новости и статьи
7. **Контакты** (`/contacts`) - Контактная информация и форма
